NUALS NETWORK ACCESS HUB
Installation Guide



Step 1: Download and Extract the Folder

Download the extension file provided to you via https://github.com/akashpattery-cmyk/NUALS-NETWORK-ACCESS-HUB/releases/latest.
It is a .zip file that you need to extract (unzip). Right-click the file and select Extract All... (on Windows) or double-click it (on Mac).
Save the extracted folder somewhere easy to find. Note: Make sure this file is never deleted from this location.



Step 2: Open Chrome’s Extension Page

Open Google Chrome (or any Chromium based browser).
In the address bar at the top, type chrome://extensions and press Enter. (Alternatively, click the puzzle piece icon in the top right of Chrome and select Manage extensions).



Step 3: Turn on Developer Mode

On the Extensions page, look in the top-right corner.
You will see a toggle switch labelled Developer mode. Click it to turn it ON (the switch will turn blue).



Step 4: Load the Extension

After turning on Developer mode, three new buttons will appear at the top left of the page.
Click the button labelled "Load unpacked".
A window will pop up asking you to select a folder. Navigate to where you saved the extracted folder in Step 1.
Select the folder and click Select Folder (or Open). Note: Make sure you select the folder that contains a file named manifest.json.



Step 5: Enter your Login Credentials

The extension is now successfully installed and active in Google Chrome!
Click the new extension icon you just pinned in the top right corner of your browser.
A small pop-up window will appear on your screen.
Enter the required credentials.
Click the Save Credentials button. You are now ready to use the extension!



Step 6: Pin the Extension for Easy Access

To make it convenient and easy to access at any time, locate and click the Puzzle piece icon (Extensions menu) in the top-right corner of your Chrome browser window, right next to your profile picture.
Scroll through the list to find the newly installed extension (e.g., NUALS NETWORK ACCESS HUB) and click the Pin icon adjacent to it. Once pinned, its icon will remain permanently visible on your browser toolbar for quick one-click configuration whenever you need to enter or update your login credentials.
